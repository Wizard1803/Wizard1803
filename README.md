## Projects

### Password Analyzer
> CLI tool that analyzes password strength using mathematical entropy,
> HaveIBeenPwned API breach lookup, mutation detection, and wordlist
> matching — because "weak" or "strong" tells you nothing useful.

**The Problem:** Common password tools give a label without explaining
*why* a password is weak or whether it's already been compromised in
real breaches. This tool gives you the full picture.

**Current Features (v1):**
Entropy scoring • Charset detection • RockYou wordlist check •
HaveIBeenPwned API • Mutation detection • Repeating char detection •
Weakness analysis

**Roadmap:** Time-to-crack estimation → Leet speak detection →
Password improvement suggestions → Flask/Next.js web UI

**Stack:** Python • HaveIBeenPwned API • RockYou Wordlist

[View Repository →](https://github.com/Wizard1803/Password-analyzer)
